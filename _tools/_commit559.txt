559: feat — populate wick H/L, sync journal to front-run geometry, harden localTP

The front-run anticipation entry (v5.57) moved the entry 0.5*ATR beyond the
edge the breakout crosses. Three leftovers still described or depended on the
old geometry: the block's Wick1/Wick2 candle fields were never written, the
journal still printed the retired v5.53 "Aggressive ... at ... Edge" wording,
and the virtual-fire commit re-derived localTP off the anticipation TRIGGER
rather than the far edge. All three are now consistent with the shipped model.

WICK H/L POPULATED (COttoBlockManager.mqh, 4 sites)

  SSniperBlock carries SFractalPeak wick1/wick2, but only wick1Time/wick2Time
  were ever assigned -- ZeroMemory() left every price 0.0, so the journal's
  " H=0.00000 L=0.00000" was structural, not a missing log. All four creation
  passes (TryCreateNewBlocks + WarmUpHistory, resistance + support) now fill
  the full candle. The stored anchors are NOT full ranges: m_w1ResTop is the W1
  iHigh() but m_w1ResBot is the W1 BODY top, and m_w1SupBot is the W1 iLow()
  while m_w1SupTop is the BODY bottom -- so the missing extreme is read from
  the series rather than reused. W2 is the pivot bar (curTop/curBot). Fields
  are display-only: no trading path reads them.

localTP HARDENED (COttoOrderManager.mqh, CheckVirtualTriggers)

  The virtual-fire commit recomputed localTP as triggerPrice +/- slDist, while
  PlaceOrArmOrder() anchors the target on the FAR edge (farEdge +/- tpRR *
  slDist). Both feed the Front-Run veto, which compares the market against
  block.localTP once an order rests, so the virtual form could let the veto
  judge a price 0.5*ATR away from the one the order was built with. The commit
  now re-derives with the identical far-edge arithmetic. Numerically identical
  at every reachable arm path (localTP already holds that value), so this is a
  consistency guarantee, not a behaviour change -- verified line by line.

JOURNAL SYNC (COttoJournal.mqh, LogSetupArmed + LogEntry)

  * Setup wording -> "Front-Run Breakdown / Sell at Bottom Edge - 0.5*ATR |
    SL at Top Edge" and the resistance mirror; the retired "Aggressive" text
    is gone from the file.
  * Both blocks now print the full zone marks (Top / Bottom / Mid / Height) so
    the rrUnit derivation (slDist = blockHeight + 0.5*ATR) is legible from the
    log alone.
  * LogSetupArmed prints 1R and the projected target; LogEntry prints Target
    alongside 1R.
  * Both Wick H/L rows are wrapped in if(wick1Time > 0 && wick2Time > 0), so a
    block with unpopulated wicks prints no bogus zero row (mirrors LogEntry's
    pre-existing guard).
