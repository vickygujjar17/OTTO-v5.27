TOOLING

_tools/_bump_version.py is a NEW generic replacement for the per-release
_bumpNNN.py scripts. Instead of hardcoding the from/to pair it auto-detects
the live release from OttoDefines.mqh, so the anchors can never rot into dead
strings, and it exits non-zero while ANY old-release literal survives in the
shipped sources or docs -- a partial bump is worse than no bump.

Historical annotations naming the release a feature LANDED in (`// v5.3x:`
notes, `FIX (vX)` markers) are deliberately untouched: any line containing
`FIX (` is skipped outright and every pattern is anchored on a human-facing
prefix rather than on the version number alone.
